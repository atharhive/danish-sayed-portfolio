# Contributing to Danish Sayed's Trading Portfolio

Contributions, design refinements, and performance enhancements are welcome!

## Getting Started Locally

```bash
git clone https://github.com/atharhive/danish-sayed-portfolio.git
cd danish-sayed-portfolio
npm install
npm run dev
```

Open `http://localhost:8090` in your browser.

## Guidelines
- Keep all components modern, dark-mode first, and high performance (60 FPS).
- Ensure no bloat or external heavy charting runtimes are imported without necessity.
- Maintain responsive layout across 390px (mobile) to 1440px (desktop) viewports.

## Maintainer Responsiveness SLA
We aim to review issues and pull requests within **24 hours**.
